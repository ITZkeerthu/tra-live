Data: Taiwan Railway (TRA) via TDX Transport Data eXchange, Ministry of Transportation and Communications, R.O.C. Live train positions come from TRA's TrainLiveBoard feed (updated about every 30 s); schedules from TRA's daily timetable. Times shown in Taiwan time (UTC+8). MRT, metro and High Speed Rail are not included.

TDX API key

Free, from the Ministry of Transportation's TDX platform. Without a key, TDX allows only a small number of requests per day per IP, which auto-refresh uses up quickly. Register at tdx.transportdata.tw, then copy your Client Id and Client Secret from Member Center → API keys. They are stored only in this browser.
